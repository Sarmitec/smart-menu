# كافتيريا جامعة اللاذقية

## التشغيل المحلي

شغّل خادماً ثابتاً من هذا المجلد، ثم افتح `index.html` عبر الخادم:

```powershell
python -m http.server 8080
```

## النشر

ارفع الملفات إلى Netlify أو Cloudflare Pages مع مجلد النشر الحالي. ملف `_headers` يضيف رؤوس الحماية والتخزين المؤقت. استبدل `example.invalid` في `index.html` بالنطاق الحقيقي، واضبط `CONFIG.whatsappNumber` في `script.js`.

لا تستخدم القائمة صوراً خارجية؛ تظهر أيقونة رمزية صغيرة بجانب اسم كل صنف.

لإنشاء أيقونات PNG المطلوبة لمتاجر التطبيقات، استخدم أداة تحويل SVG إلى PNG خارج هذا المشروع وأنشئ `icon-192.png` و`icon-512.png` و`icon-maskable-512.png`، ثم أضفها إلى `manifest.webmanifest`.

تنبيه: الحماية في الواجهة الأمامية تقلل الأخطاء والإساءة العرضية، لكنها لا تثبت صحة الطلب أو السعر أمام مستخدم متحكم بالمتصفح؛ يلزم خادم للتحقق النهائي.
